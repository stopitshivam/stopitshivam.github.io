# Shivam Sharma — Academic Website

A minimal, responsive academic profile website for Shivam Sharma.

## Files
- `index.html` — the complete website (HTML and CSS are included in this file).

## Publish with GitHub Pages
1. Open the repository `stopitshivam/stopitshivam.github.io`.
2. Upload `index.html` to the repository's root directory.
3. Commit the change to the `main` branch.
4. In **Settings → Pages**, ensure the source is set to deploy from `main` and the `/(root)` folder.

The website will be available at: https://stopitshivam.github.io

## Updating the website
Edit `index.html`, save it, and commit the updated file to `main`. GitHub Pages will publish the change automatically.

## Privacy
This page includes only the institutional email address supplied for the website. It does not include a photograph, phone number, personal email address, CGPA, or percentage scores.
